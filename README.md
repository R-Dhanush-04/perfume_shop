# Luxury Shop — Haute Parfumerie 🌟

A luxury perfume storefront demo built with React and Vite, featuring multi-angle product imagery, scent-note profiles, cart and wishlist interactions, product filtering, and a simulated checkout.

## ✨ Features

- **Immersive Visuals**: High-resolution multi-angle perfume photography (Front, Side, Back, Detail shots).
- **Interactive Scent Profiles**: Top, Heart, and Base note pyramids with intensity gauges.
- **Dynamic Filtering & Search**: Filter by scent families (Woody, Oriental, Floral, Fresh, Gourmand) and gender collection.
- **Cart & Wishlist**: Browser-local shopping bag and wishlist with slide-over drawer.
- **Responsive & Modern UI**: React, Vite, and custom luxury gold/dark styling with reduced-motion support.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/R-Dhanush-04/-Luxery_Shop.git
   cd -Luxery_Shop
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

## 🛠️ Tech Stack

- **Frontend**: React 18
- **Icons**: Lucide React
- **Build Tool**: Vite
- **Styling**: Vanilla CSS with custom design tokens

## Demo limitations

This repository is a frontend demonstration. Login/register, order confirmation, ratings, newsletter submission and checkout are not connected to a backend, real customer review service, email provider or payment gateway. Do not enter real payment credentials. Connect a secure backend and payment provider before production use. Product longevity and fragrance-note descriptions are illustrative and should not be treated as verified performance claims.
